# PDF Tools

Ferramentas de PDF que rodam 100% no navegador (nenhum arquivo é enviado a servidores).

## Funcionalidades
- **Reordenar PDF:** arraste as páginas, gire, remova, inverta a ordem e dê zoom nas miniaturas.
- **Mesclar PDF:** combine vários PDFs em um só, definindo a ordem dos arquivos.
- **Extrair páginas:** selecione páginas por clique ou por intervalo (ex.: `1-3, 5, 8-10`) e gere um novo PDF.

## Como usar
Abra o `index.html` no navegador (ou acesse a versão publicada no GitHub Pages).

## Tecnologias
HTML, CSS e JavaScript puro, com [pdf.js](https://mozilla.github.io/pdf.js/), [pdf-lib](https://pdf-lib.js.org/) e [SortableJS](https://sortablejs.github.io/Sortable/) via CDN.
